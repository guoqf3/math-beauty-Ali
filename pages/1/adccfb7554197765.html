最短路径 · 节点边生命

Dijkstra 松弛

d[v] ← ∞,  d[s] ← 0
Q ← V  // 优先队列
while Q ≠ ∅:
  u ← extract-min(Q)
  for v ∈ adj[u]:
    if d[u]+w(u,v) < d[v]:
      d[v] ← d[u]+w(u,v)
      π[v] ← u  // 前驱
复杂度 O((V+E) log V)

A* 启发式估值

f(n) = g(n) + h(n)
g(n) ：s → n 已知实际代价
h(n) ：n → t 启发估计
if h ≤ h* ⇒ 最优解
if h=0 ⇒ 退化为 Dijkstra
欧氏距离启发式：
h(n)=√((xₙ−xₜ)²+(yₙ−yₜ)²)

能量 / 张力模型

E = Σ Φ(dij − L)²
节点受力弹簧回弹，边越短越亮
w(u,v) ∝ ‖pu − pv‖
脉冲沿 α→β 最短路径 ∝ 光强
