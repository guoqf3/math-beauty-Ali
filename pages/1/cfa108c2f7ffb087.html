球面均匀分布

用 斐波那契球面 在单位球上撒 N 个近似均匀的点， 避免极点聚集。i 从 0 到 N−1：

Fibonacci Spherei = 0 … N−1
yᵢ = 1 − 2(i + 0.5) / N
rᵢ = √(1 − yᵢ²)
φᵢ = i · 2π / φ²  (φ = 1.618…)
Pᵢ = ( rᵢ cos φᵢ , yᵢ , rᵢ sin φᵢ )

径向正弦波动

每个刺突沿球面法线方向伸出，长度由一道在球面上行进的 正弦波决定 —— 尖端位置 = 单位方向 × (1 + L)。

Rᵢ(t) = ( 1 + Lᵢ(t) ) · P̂ᵢ
